# YouTube 視聴済み管理 Chrome拡張機能

YouTubeの動画サムネイルに視聴済み/未視聴のバッジを表示し、
動画ページのボタンや自動再生判定によって視聴状態を管理する拡張機能です。

## インストール方法(開発者モードでの読み込み)

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このリポジトリのフォルダ(`manifest.json` があるディレクトリ)を選択する
5. YouTube (`https://www.youtube.com`) を開くとバッジ・ボタンが表示される

### コードを更新した場合

ファイルを差し替えただけではYouTube側のタブをリロードしても反映されないことがあります。
`chrome://extensions` で本拡張の「再読み込み」ボタンを押してから、YouTubeのタブを開き直してください。

## 機能概要

- サムネイル**左上**に視聴済み(半透明緑・☑)/未視聴(半透明赤・□)のバッジを表示
  - ホーム画面・検索結果・チャンネルページ・再生リストなど、サムネイルが表示される全ページが対象
- 動画再生ページでは、**動画プレーヤー左上**に視聴済み/未視聴の切替ボタンをオーバーレイ表示
  - クリックで手動トグル可能(自動判定後もいつでも未視聴に戻せる)
  - ボタン色はサムネイルバッジと統一(視聴済み=緑 / 未視聴=赤)
  - ボタン操作は動画本体のクリック・シーク操作に影響しない
- タブがアクティブな状態での再生時間を計測し、設定した閾値(再生割合または再生時間、いずれか早い方)に
  到達すると自動的に視聴済みにする
- 視聴状態は `chrome.storage.local` に保存され、ブラウザ再起動後も保持される
- 同じGoogleアカウントでログインした**別端末のChrome間で視聴済み状態を自動同期**する
  (`chrome.storage.sync` を利用。詳細は下記「複数端末間の自動同期」を参照)

## 設定

拡張機能一覧の本拡張の「詳細」→「拡張機能のオプション」から以下を行えます。

- 自動視聴済み判定のしきい値(再生割合・再生時間)の変更(初期値:割合50% / 時間10分)
- 視聴状態データのエクスポート・インポート(下記参照)

## 複数端末間の自動同期

同じGoogleアカウントでログインし、Chromeの同期を有効にしている端末同士であれば、
拡張機能を操作するだけで視聴済み状態が自動的に同期されます(手動操作は不要)。

### 仕組み

- `chrome.storage.sync` を使い、background service worker がローカルの視聴状態の変化を
  検知して同期用ストレージへ反映し、他端末からの変化もローカルへ反映します
- `chrome.storage.sync` は「合計サイズ100KB・最大512アイテム」という上限があるため、
  動画1本=1アイテムでは足りなくなります。本拡張では動画IDのハッシュ値をもとに
  複数の動画IDを1アイテム(バケット)へまとめて格納する方式を採っており、
  理論上**5,600件以上**の視聴済み動画を同期できます
- 同期はイベント駆動で行われ、定期的なポーリング(監視ループ)は行いません。
  実際に視聴済み/未視聴が切り替わった時、または他端末からの変化が届いた時にのみ動作するため、
  Chromeの負荷はほとんどありません
- `chrome.storage.sync` はアイテム単位で同期されるため、複数端末がほぼ同時に同じ
  データへ書き込むと理論上は競合が起こり得ます。本拡張では書き込み直前に必ず最新状態を
  取得してから差分を適用し、書き込み後に反映を検証してズレていればリトライする、
  という方式でこの競合の窓をできる限り狭めています(通常利用ではまず問題になりません)

## 視聴状態のエクスポート・インポート

視聴済み/未視聴のデータをJSONファイルとして書き出し、別のPC・別のChromeプロファイルに取り込むことができます。
上記の自動同期とは別に、バックアップや、Chromeの同期を使わない環境への手動移行手段として利用できます。

- **エクスポート**:オプション画面の「エクスポート」ボタンで `yt-watched-status-YYYY-MM-DD.json` をダウンロード
- **インポート**:別環境のオプション画面で「インポート」ボタンからそのJSONファイルを選択

インポート時、同じ動画IDのデータが両方に存在する場合は、更新日時(`updatedAt`)が新しい方が自動的に採用されます。
なお、自動判定のしきい値設定はエクスポートに含まれません(視聴状態データのみが対象です)。

## 既知の制限・今後の調整が必要な点

- YouTube側のDOM構造は変更される可能性があります。
  サムネイル検出は「動画へのリンクかつ画像を含む要素」という汎用的な条件で行っているため、
  ある程度のデザイン変更には自動的に追従しますが、それでも崩れる場合は
  `src/shared/constants.js` の `SELECTORS` および `src/content/domObserver.js` の検出ロジックを見直してください
- バッジ・ボタンの位置やサイズは `src/styles/overlay.css` で調整できます
- ホーム画面などサムネイルが極端に多いページでのパフォーマンスは、実運用で問題があれば
  IntersectionObserverによる遅延描画などの追加最適化を検討してください
- 自動同期は`chrome.storage.sync`の仕様上、複数端末がオフラインのまま同時に操作を行った場合など、
  ごく稀に反映が一時的にズレる可能性があります。気になる場合はエクスポート/インポートで補正してください

## ディレクトリ構成

```
yt-watched-status-extension/
├── manifest.json
├── README.md
└── src/
    ├── background/
    │   └── service-worker.js       … chrome.storage.local ⇔ .sync の橋渡し(自動同期)
    ├── content/
    │   ├── content-script.js       … エントリーポイント
    │   ├── domObserver.js          … サムネイル検出・SPAページ遷移検知
    │   ├── thumbnailOverlay.js     … サムネイルへのバッジ描画
    │   ├── videoPageButton.js      … 動画プレーヤー左上の視聴済み切替ボタン
    │   └── playbackTracker.js      … 自動視聴済み判定(再生時間トラッキング)
    ├── options/
    │   ├── options.html            … 設定画面(しきい値設定・エクスポート/インポート)
    │   ├── options.js
    │   └── options.css
    ├── shared/
    │   ├── constants.js            … storageキー・デフォルト値・セレクタ・同期バケット設定
    │   ├── videoId.js              … URLから動画ID抽出
    │   ├── storage.js              … chrome.storage.local 共通ラッパー
    │   └── syncStorage.js          … chrome.storage.sync 用ハッシュバケット同期ロジック
    └── styles/
        └── overlay.css             … バッジ・ボタンの見た目
```
